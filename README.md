# Norlay

This is the special `.github` repository for the [Norlay organization](https://github.com/NorlayOfficial).

The organization profile README lives at [`profile/README.md`](profile/README.md) and is what you see on [github.com/NorlayOfficial](https://github.com/NorlayOfficial).

This repository also holds the default community health files for every Norlay repository: the code of conduct, the security policy, contribution guidance, and the issue templates. A repository that needs something more specific can override any of them with its own copy.

- Website: [norlay.fit](https://norlay.fit/)
- Release downloads: [NorlayOfficial/norlay-releases](https://github.com/NorlayOfficial/norlay-releases)
- Norlay Link Checker source: [NorlayOfficial/norlay-link-checker](https://github.com/NorlayOfficial/norlay-link-checker)
- Feedback: [norlay.fit/feedback](https://norlay.fit/feedback)
- Facebook: [NorlayOfficial](https://www.facebook.com/NorlayOfficial)
