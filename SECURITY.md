# Security policy

## Reporting a problem

Please do not open a public issue for a security problem. Use GitHub's private
reporting instead: **Security → Report a vulnerability** on the repository where
the problem lives, or on the organization page at
<https://github.com/NorlayOfficial>.

Include the product and version, what you expected and what happened. Do not
include a real API key, a private link, or someone else's personal data.

Reports are acknowledged within a few days. If a repository has its own
`SECURITY.md`, follow that one — it knows more about the product in question.

## Supported versions

Only the latest release of each product receives fixes. Older versions can be
updated from the product page on [norlay.fit](https://norlay.fit/) or from
[Norlay releases](https://github.com/NorlayOfficial/norlay-releases).

## What our products do with your data

Each product page states this in full. The short version: Norlay products run on
your own machine, keys stay on your machine, and there is no Norlay telemetry.
Anything that contradicts a product's stated privacy behaviour is a security
problem, and we would rather hear about it privately.
